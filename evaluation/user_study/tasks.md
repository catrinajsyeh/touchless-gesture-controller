# Task card

Say this once the TikTok video is open and focused.

"You will next, previous, like, pause, and play. On the keyboard that is Up, Down, L, Space, Space. With the controller, use index-up, index-down, thumbs-up, and an open palm. Open palm toggles pause. Return your hand to a relaxed pose between actions. I will time from when I say start until the video is playing again."

Poses, for the experimenter:

- Index up: other fingers folded, fingertip toward the ceiling.
- Index down: same hand, fingertip toward the floor.
- Thumbs up: thumb clearly to the side, not just a pointing finger.
- Open palm: all four fingers spread.
- Between actions: pull the hand down or make a fist so the model can see no gesture.
